# Bassin v2.1.11 reviewer screenshots

These PNGs show the production frontend from commit `af433d3fbddcf60009aa08f98d45edd8ce725226`, for getumbrel/umbrel-apps PR #6167.

Captured directly in Chromium at 2× device scale, with no image enlargement or retouching:

- Home: 1920 × 2200
- Bitcoin Node settings: 1920 × 2200
- Notification controls: 1920 × 2200
- Insights and workers: 1920 × 3200

Pool statistics, worker records, hashrate history, CKPool version metadata, and RPC configuration are synthetic fixtures. The chart samples are simulated for illustration. The displayed RPC credentials are sample values, not real credentials. No visitor IP lookup or geolocation was used.

The browser clock/timezone uses UTC and reduced motion is enabled for still captures. Fonts were loaded before capture; transient notifications and hover/focus outlines were cleared. These are visual review assets, not evidence of a physical Umbrel runtime test. The PR separately documents maintainer-reported UmbrelOS 2.0 testing on a Raspberry Pi Compute Module 5 in a CmRat by DTV Electronics.

The official App Store gallery artwork is hosted and prepared separately by the Umbrel team. These files are kept outside the official app package.
